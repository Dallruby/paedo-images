**컨셉** 2004년 단월사립고 학생들의 싸이월드 미니홈피를, 모바일 세로형으로 재편

## 1. 파일 구조

```
index.html      전부 여기 들어 있음. 빌드 없음, 의존성 없음
bgm/            브금 5개 (연결 완료)
  you.mp3  junrae.mp3  wonho.mp3  seolhee.mp3  suhyun.mp3
img/            비어 있음. 여기에 이미지를 넣으면 자동으로 붙음
```

index.html 은 `<style>` / 마크업 / `<script>` 세 덩어리다. 스크립트 안은 위에서부터
**DATA 객체 → 렌더 함수 → 이벤트 핸들러** 순.

타이틀 로고는 base64 로 HTML 안에 박혀 있어서 별도 파일이 필요 없다.

## 2. 화면 구조

```
인트로 (Y2K 밝은 톤, 로고 등장)
   ↓ 내 미니홈피 가기  ← 여기서 오디오 자동재생 권한 획득
YOU 미니홈피
   ↕ 이동 두 가지
     · 상단 파란 바의 [파도타기]  → 자기 빼고 랜덤 이동, 파도 전환 연출
     · 방명록 / 일촌평의 이름 클릭 → 그 사람 미니홈피
     · 상단 [내 미니홈피]         → YOU 로 복귀
```

미니홈피 내부는 오른쪽 세로 인덱스 탭 4개.
**홈 / 다이어리 / 사진첩 / 방명록**

- 홈 = 미니룸 + 일촌평 + 개수 요약
- 다이어리 = 제목 누르면 펼침. 잠긴 글 3종 (일반 잠금 / 삭제됨 / 비밀번호)
- 사진첩 = 사진 + 캡션 + 댓글 접기
- 방명록 = 번호 역순, 비밀글, 답글

## 3. DATA 스키마

인물 5명이 `DATA` 객체 안에 키로 들어 있다. 키는 `user junrae wonho seolhee suhyun`.
**콘텐츠 수정은 전부 이 안에서만 하면 된다.**

```js
{
  name:"마준래",           // 표시용 이름
  title:"마준래",          // 미니홈피 제목 (헤더 가운데)
  mine:true,              // YOU 에게만. 방문 카운터가 안 오름
  skinName:"기본스킨 (무료)", // 있으면 홈 하단에 표시. YOU 에만 있음
  pop:{today:[236,468], total:[26400,31200]},  // 접속할 때마다 이 범위에서 랜덤
  skin:{ ... },           // 4항 참고
  miniroom:"img/miniroom_junrae.png",
  bgm:{file:"bgm/junrae.mp3", title:"아무것도 묻지 ㅁr"},

  ilchon:[ {who, go, nick, txt} ],
  // go 가 있으면 이름이 링크가 되어 그 인물로 이동. 값은 DATA 의 키

  diary:[
    {pin:1, date, title, body},          // 일반 글. pin 이면 [고정] 배지
    {date, lock:1},                      // 눌러도 "주인만 볼 수 있는 글"
    {date, del:1},                       // 삭제된 글 (취소선, 클릭 불가)
    {date, title, pw:"1109", hint:"...", body}  // 비밀번호 입력해야 열림
  ],

  photo:[ {src, cap, dt, cn:47, cm:[{w,t}]} ],
  // cn = 표시용 댓글 총 개수. cm 은 실제로 보여줄 일부.
  // cn > cm.length 면 "외 N개" 가 붙는다. 정설희 인기 연출용

  guest:[
    {who, go, dt, body, re:"└ 답글"},
    {sc:1, dt}                           // 비밀글
  ]
}
```

`body` 안의 `\n` 이 그대로 줄바꿈된다 (`white-space:pre-line`).

## 4. 스킨 시스템

`skin` 객체의 값이 `.sheet` 와 `.tabs` 에 **CSS 변수로 인라인 주입**된다 (`render()` 안).
색을 바꾸려면 여기만 고치면 페이지 전체가 따라간다.

| 변수 | 쓰임 |
|---|---|
| `paper` `pat` `patsz` | 종이 바탕색 / 무늬 / 무늬 크기 |
| `card` | 방명록·사진·BGM바 등 카드 배경. **다크 스킨에서 이게 핵심** |
| `edge` `line` | 바깥 테두리 / 내부 선 |
| `accent` `accent2` | 강조색 / 밝은 강조색 (그라데이션용) |
| `soft` | 옅은 배경 |
| `tabbg` `tabtx` | 인덱스 탭 |
| `ring` `ringf` | 제본 링 |
| `dim` `txt` | 흐린 글자 / 본문 글자 |

현재 스킨

- **YOU** 흰색, 무늬 없음 (은따·가난 코드. 유일하게 스킨 이름이 표시됨)
- **마준래** 검정 + 대각선. 다크 스킨이라 `card` `txt` `dim` 값이 다른 인물과 반대
- **민원호** 흰색 + 모눈종이
- **정설희** 분홍 + 세로 스트라이프
- **이수현** 노랑 + 깅엄 체크

새 인물을 추가하면 `DATA` 에 키를 넣고 `ORDER` 배열에도 추가해야 파도타기 대상이 된다.

## 5. 인물과 비닉설정

전원 1학년 동갑. **오빠·언니·형님 호칭 금지.**

| | 포지션 | ㊙️ |
|---|---|---|
| YOU | 전학생, 은따, 가난 | 원래 잘살았고 민원호 옆집이었음. 집안이 망해 2002년 이사 |
| 마준래 | 단월고 짱 | 작년 사건을 혼자 뒤집어씀. 해명하지 않음 |
| 민원호 | 반장, 엄친아 | 뒤집어씌운 당사자. 집안 때문에 침묵 |
| 정설희 | 얼짱, 노는 무리 리더 | 사건 목격자. 침묵의 대가로 민원호 집안과 엮임 |
| 이수현 | YOU의 유일한 편, 소식통 | 민원호를 좋아함. 후반에 배신 |

### 비닉설정 노출 3층 원칙

사이트는 읽기 전용이라 설명이 불가능하다. 그게 오히려 맞다.

| 층 | 방식 | 실제 배치 |
|---|---|---|
| 표면 | 그냥 읽힘 | 정설희가 YOU 방명록에 남긴 비꼼 |
| 잠김 | 존재만 보임 | 민원호 다이어리 2003.11 연속 🔒 5개 |
| 공백 | 없는 게 단서 | 마준래 2003년 글 전부 삭제 / YOU 다이어리 2002~2004 2년 공백 |

**인과는 절대 서술하지 않는다.** 진실은 본편 프롬프트에서만 열린다.

라일락 장치: YOU 의 2002.05 글 "담 넘어서 옆집까지 넘어갔다" 와
민원호의 2002.05 글 "라일락이 우리집 마당까지 넘어왔다" 가 짝이다. 건드리지 말 것.

### 비밀 다이어리 비밀번호

| 인물 | 비번 | 힌트가 가리키는 곳 |
|---|---|---|
| 마준래 | 1109 | 삭제된 글의 마지막 날짜 |
| 민원호 | 0509 | 자기소개 릴레이의 생일 |
| 정설희 | 0707 | 자기소개 릴레이의 생일 |
| 이수현 | 0330 | 자기소개 릴레이의 생일 |

YOU 의 잠긴 글은 비번이 없다. 영영 안 열린다. 플레이어의 속마음을 고정하지 않기 위함.

## 6. 시대 고증 규칙

원전 인터넷소설 19편 실측에 기반한 규칙. **콘텐츠를 추가할 때 반드시 지킬 것.**

**금지**
`ㅋㅋ` `ㅎㅎ` — 2010년대 카톡체다. 원전 834만 자에 사실상 없음. 시대가 제일 크게 어긋나는 요소
카톡 / 스마트폰 / 인스타 / 셀카 / 현대 문물 전반
`대박` `킹카` `얼짱` 남발 — 원전에서 희소하다. 얼짱은 정설희 라인에만

**써야 하는 것**
- 이모티콘: `-0- =_= -_-^ ㅠ0ㅠ ㅜ_ㅜ ㅇ_ㅇ ^-^ >_< =0= >ㅁ< ㅡ_ㅡ ..;; ..=_=..`
  대사 끝에 하나만. 현재 30종이 빈도별로 분산돼 있다. `-0-` 편중 주의
- 구어: `니/니가`(너보다 기본형), `하구 이구 그리구 그치 같애 맞어`

- 소품: 폴더폰 문자(80자), 공중전화, 부재중, 컬러링, 다모임, 버디버디, 배틀넷,
  쭉빵카페, 도토리, MP3 압수, 마이, 옥상, 매점, 야자, 담탱

## 7. 코드 동작 메모

- **렌더** `render()` 가 헤더 + BGM바 + 탭별 본문을 통째로 `innerHTML` 로 갈아끼운다.
  본문을 `.pgin` 으로 감싸서 매번 등장 애니메이션이 다시 걸린다
- **이벤트** 전부 `document` 위임. `data-go` `data-tab` `data-d` `data-p` `data-ok` `data-bgm`
- **이미지 폴백** `slot()` 이 회색 자리와 `<img>` 를 같이 뱉고, 로드 성공하면 자리를 지운다.
  이미지가 없어도 레이아웃이 안 무너진다
- **오디오** 브라우저 정책상 첫 터치 없이 재생 불가. 인트로 버튼이 그 터치 역할을 한다.
  이후 인물 이동 시 자동 교체. 실패하면 `noAudio=true` 로 "음원 없음" 표기
- **상태** `who` `tab` `OPEN`(푼 비번) `HIT`(카운터) 전부 메모리. 새로고침하면 초기화
- **PC** 760px 이상이면 폰 목업 프레임 안에 들어간다. 모바일은 전체화면

## 8. 남은 작업

### 바로 해야 할 것
이미지 투입. 아래 이름 그대로 `img/` 에 넣으면 붙는다. 전부 **가로 4:3** 권장.

```
miniroom_user  miniroom_junrae  miniroom_wonho  miniroom_seolhee  miniroom_suhyun   .png
photo_user_1~2   photo_wonho_1~3   photo_seolhee_1~6   photo_suhyun_1~2            .jpg
```

마준래는 사진첩이 0장이 정상이다 (캐릭터 코드).

### 디벨롭 후보
1. **다이어리 페이지형** 지금은 아코디언인데 원본은 글 하나가 한 페이지였다. 이전글/다음글
2. **방명록 페이징** 정설희 19개가 한 번에 쏟아진다. 5개씩 끊고 `1 2 3 ▶`
3. **다이어리 월 달력** 글 쓴 날에 점이 찍히던 그 UI. 비공개 날짜만 점이 찍혀 있으면 그 자체가 단서
4. **미니미 말풍선** 미니룸에 미니미를 세우고 탭하면 한마디
5. **일촌 신청 버튼** YOU 홈에만. 눌러도 거절되는 식
6. **크랙 연재 링크 CTA** 위치 미정. 인트로 하단 또는 YOU 홈 최하단

### 안 건드릴 것
- 본문 텍스트를 늘릴 때 6항 고증 규칙
- 비닉설정을 설명으로 풀지 말 것
- YOU 는 이름 없이 `YOU` 로만 표기
- 하단 고정바를 되살리지 말 것 (이동은 파도타기와 이름 클릭 두 가지로 확정)
